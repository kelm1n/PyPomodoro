# PyPomodoro

**PyPomodoro** - приложение для управления временем по технике Pomodoro. Помогает организовать рабочие сессии, с последующей сменой времени концентрации на перерыв

## Возможности

- Таймер рабочих сессий и перерывов
- Запуск, пауза и сброс таймера
- Настройка продолжительности работы
- Отображение прогресса сессии
- Статистика завершенных рабочих сессий
- Сохранение настроек и статистики
- Работа на фоне в системном трее
- Горячие клавиши
- Звуковое уведомление об окончании сессии

## Технологии

- Python
- PyQt6
- JSON

## Установка и запуск

Клонируйте репозиторий git clone <ссылка>
Войдите в папку проекта cd PyPomodoro-end
Установите виртуальное окружение python -m venv .venv
Установите зависимости, библиотеки pip install -r requirements.txt
Запустите программу на выполнениеpython main.py
